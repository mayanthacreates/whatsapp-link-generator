# Security Policy

This is a small, static, open-source tool maintained by one person.

## Reporting a vulnerability

If you find a security issue, please report it privately:

- Email: **hey@mayantha.net**
- Or open a [GitHub security advisory](../../security/advisories/new)

Please do not open a public issue for security problems.

I aim to acknowledge reports within 72 hours and to fix confirmed issues as quickly as I can. Coordinated disclosure is appreciated - give me a reasonable window to ship a fix before publishing.

## Scope

The code in this repository and the single page it deploys to. These tools run entirely in the browser and hold no user accounts or server-side data.
